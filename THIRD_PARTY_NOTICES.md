## 5. Compliance notes for this project

- **Keep the project noncommercial.** No ads, no paywall, no charge for the app
  or the hosted dashboard. Donations are allowed by the rules; advertising is
  not.
- **Keep the notice reachable.** The rules require the notice in §1 to be easy to
  find from wherever the project is shared — link this file from `README.md`
  and keep the "not endorsed by or affiliated with Microsoft" line in the
  dashboard footer.
- **The reverse-engineering restriction is a real tension.** This project
  interoperates with the game service by replaying a login exchange observed in
  packet captures, including the `xlive.dll` CRC-32 and a per-install device
  fingerprint, and it extracts the Dismantler guide from game assets. The Game
  Content Usage Rules' first restriction prohibits reverse engineering to access
  assets or to do things the games do not normally permit. Nothing in this file
  grants that permission, and Microsoft's rules do not govern the Project
  Celeste servers at all — automated access to those is subject to Project
  Celeste's own terms. Treat this as the project's main legal risk, keep it
  noncommercial, and be prepared to stop distributing the derived game content
  on request.
- **Independence.** This project is not endorsed by or affiliated with Microsoft
  or with Project Celeste.
